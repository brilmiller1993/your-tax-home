# Your TAX HOME

Static website prototype for tax preparer, service bureau, and office manager training.

## Import into Lovable

1. Connect your GitHub account in Lovable.
2. Import **brilmiller1993/your-tax-home** from the `main` branch.
3. The site entry point is `index.html` at the repository root.
4. Review the import, then publish from Lovable.

You can also enable GitHub Pages from **Settings → Pages** and publish from the `main` branch root.

Live preview: https://your-tax-home.brilmiller1993.chatgpt.site

## Demo limitations

This static preview keeps demo signups and brand settings in the current browser only. It does not provide secure login, shared account administration, or real document uploads. Do not enter taxpayer or identity documents. Connect a secure backend before using those workflows with real people.
